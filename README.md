# Ξύπνα — ξυπνητήρι με μαθηματικά (τύπου Alarmy)

## Τι κάνει
- Πολλά ξυπνητήρια, με επανάληψη ανά μέρα και ετικέτα
- Χτυπάει με κλειδωμένη οθόνη, στη μέγιστη ένταση, με δόνηση
- Σβήνει **μόνο** αν λύσεις τις πράξεις (Εύκολο / Μέτριο / Δύσκολο, 1–10 πράξεις)
- Το «πίσω» δεν το σβήνει· αν ανοίξεις την εφαρμογή, σε γυρνάει στις πράξεις
- Κουμπί «Δοκιμή σε 10 δευτερόλεπτα»
- Ξαναπρογραμματίζει τα ξυπνητήρια μετά από επανεκκίνηση του κινητού

## Τρόπος Α — Android Studio (στον υπολογιστή)
1. Κατέβασε το Android Studio (δωρεάν): developer.android.com/studio
2. Αποσυμπίεσε το `Xypna.zip` και άνοιξε τον φάκελο `Xypna` (File → Open).
3. Περίμενε να τελειώσει το «Gradle sync» (την πρώτη φορά κατεβάζει αρκετά, 5–15 λεπτά).
   Αν ρωτήσει για Gradle wrapper, πάτα OK.
4. Στο κινητό: Ρυθμίσεις → Πληροφορίες τηλεφώνου → πάτα 7 φορές τον «Αριθμό έκδοσης»
   → μετά Επιλογές προγραμματιστή → USB debugging ON.
5. Σύνδεσε το κινητό με καλώδιο και πάτα το πράσινο ▶ (Run).
   Ή: Build → Build APK(s) και στείλε το .apk στο κινητό.

## Τρόπος Β — χωρίς Android Studio (GitHub)
1. Φτιάξε repository στο github.com και ανέβασε όλα τα αρχεία του φακέλου.
2. Καρτέλα **Actions** → «Build APK» τρέχει μόνο του (~5 λεπτά).
3. Από το τέλος της σελίδας κατέβασε το `Xypna-apk` → μέσα είναι το `app-debug.apk`.
4. Άνοιξέ το στο κινητό και επίτρεψε «εγκατάσταση από άγνωστες πηγές».

## Μετά την εγκατάσταση
Στην αρχική οθόνη εμφανίζονται πορτοκαλί κάρτες ⚠️ για ό,τι άδεια λείπει — πάτα
«Ενεργοποίηση» σε καθεμία μέχρι να εξαφανιστούν. Μετά πάτα «Δοκιμή σε 10 δευτερόλεπτα»
και κλείδωσε την οθόνη.

**Xiaomi / Redmi / POCO:** Ρυθμίσεις → Εφαρμογές → Ξύπνα → ενεργοποίησε «Αυτόματη έναρξη»
και στις Άλλες άδειες το «Εμφάνιση αναδυόμενων παραθύρων στο παρασκήνιο» + «Εμφάνιση στην οθόνη κλειδώματος».
**Samsung:** Μπαταρία → Ξύπνα → «Χωρίς περιορισμούς».
